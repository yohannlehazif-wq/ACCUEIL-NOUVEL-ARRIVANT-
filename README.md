# Mission Accueil

Jeu interactif de simulation pour prolonger une sensibilisation sur l'accueil des nouveaux et jeunes salariés.

## Contenu
- `index.html` : application complète, autonome et sans dépendance externe.
- 4 profils : intérimaire, apprentie mineure, nouvelle embauchée ayant besoin de repères visuels, jeune en premier emploi.
- 6 étapes : préparer, accueillir, former, pratiquer, vérifier, suivre.
- Score, confiance, maîtrise du risque, situations spécifiques, mode animateur et débrief imprimable.

## Utilisation locale
Double-cliquer sur `index.html`. Une connexion internet n'est pas nécessaire.

## Publication sur GitHub Pages
1. Créer un dépôt GitHub vide.
2. Déposer `index.html` et `README.md` à la racine du dépôt.
3. Dans **Settings > Pages**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
5. GitHub affiche ensuite l'adresse publique du jeu.

## Animation conseillée
- 2 à 4 équipes.
- 15 à 25 minutes après le diaporama.
- L'équipe argumente avant chaque clic.
- L'animateur active le « Mode animateur » pour afficher des questions de relance.
- Le débrief final sert à choisir une action applicable au prochain accueil réel.

## Confidentialité
Aucune donnée n'est envoyée ou enregistrée. Tout fonctionne dans le navigateur.
