# Mission Accueil RESTEV - code complet autonome

Le fichier `Mission_Accueil_RESTEV_Code_Complet_Autonome.html` contient :
- le HTML ;
- le CSS ;
- le JavaScript ;
- le logo RESTEV en Base64 ;
- toutes les illustrations SVG en Base64 ;
- les 24 situations adaptées aux quatre profils ;
- les questions bonus, incidents, jokers, scores et débriefs.

Il peut être renommé `index.html` et déposé seul sur GitHub Pages.

Pour modifier les questions, recherchez `const scenarios={`.
Pour modifier les profils, recherchez `const profiles=[`.
